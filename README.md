# 注意

这是仅供逆向学习参考用的开源程序，永远不要相信网上各种卖钱的以及要加群私聊之类的牛皮癣广告私服  
为避免争议，本程序仅支持体验服且不会提供体验服下载，请自行解决问题  

## 游戏安装与食用指南

下载https://github.com/nyfair/zigrika-buildbot/releases ，将所有文件解压到同一目录，运行3个exe文件  
下载https://git.xeondev.com/WavyRooms/helios/releases ，将这些文件放入游戏安装目录\\Client\\Binaries\\Win64  
下载https://git.xeondev.com/RabbyDevs/zigrika-pakfile/releases ，将这些文件放入游戏安装目录\\Client\\Content\\Paks  
用管理员权限运行helios\_launcher.exe  
启动游戏后，在左上角登录ip填http://127.0.0.1:10001

自行构建可参考[该编译脚本](https://github.com/nyfair/zigrika-buildbot/blob/master/.github/workflows/ww.yml)
